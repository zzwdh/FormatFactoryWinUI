# 2026-10-06 语言扩展

Format Factory WinUI 的界面语言从 15 种扩展到 24 种，保留“跟随 Windows”选项。新增 9 种语言，每种覆盖当前 1,116 个有效资源键，共补充 10,044 条资源。

| 语言 | 界面与安装包代码 | 设置中的名称 |
| --- | --- | --- |
| 丹麦语 | da-DK | Dansk |
| 匈牙利语 | hu-HU | Magyar |
| 罗马尼亚语 | ro-RO | Română |
| 瑞典语 | sv-SE | Svenska |
| 挪威语（书面语） | nb-NO | Norsk bokmål |
| 芬兰语 | fi-FI | Suomi |
| 捷克语 | cs-CZ | Čeština |
| 希腊语 | el-GR | Ελληνικά |
| 乌克兰语 | uk-UA | Українська |

新增语言覆盖设置、队列、历史、自动化、转换流程、设备操作及错误提示。资源采用 UTF-8 JSON，嵌入 Core 程序集，与现有资源目录共同解析；原有 15 种语言的表格结构保留。加载时检查完整键集合、空值、重复键及格式占位符，保留参数重复次数、格式说明和文件名模板中的 `{name}`、`{format}`、`{date}`。

系统语言支持按语言前缀匹配，例如瑞典语（芬兰）使用瑞典语资源。`no` 和 `nb` 映射到挪威书面语。手动选择语言时，文件大小等数字采用该语言的区域格式；跟随 Windows 时保留系统的数字格式。设置开关及输出设置中的启用、关闭状态文字也跟随应用语言。
