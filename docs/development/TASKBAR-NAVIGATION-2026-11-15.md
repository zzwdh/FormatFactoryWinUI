# 任务栏右键导航改版

已在源码中将原先仅有“设置”的任务入口扩展为 11 个导航入口，沿用应用内的页面和筛选逻辑。

## 菜单结构

最近输出单独显示，最多 3 个，按完成时间倒序排列，重复路径和已不存在的输出不会出现。

系统“任务”区按以下顺序排列，各入口使用与应用内导航相同语义的独立蓝色图标：

1. 全部任务
2. 视频
3. 音频
4. 图片
5. 文档
6. 电子书
7. 光盘与镜像
8. 压缩包互转

分隔线之后为自动化、转换历史、设置。名称沿用当前语言资源；新增的分组/提示文本覆盖全部 44 种语言。

固定入口使用 Windows 原生 Tasks，避免自定义目标分类的条目预算和最近项目偏好影响导航；只有最近输出使用自定义分类。若系统拒绝最近输出分类，会重试保存固定任务。依据：[Microsoft Jump List 分类限制](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-icustomdestinationlist-appendcategory)。

## 行为

- 新增 `--navigate:<目标>` 启动参数，只接受现有的 11 个页面标识。
- 冷启动请求与已有实例请求复用现有单实例激活队列；切换页面后等待当前导航过渡完成，保持请求顺序。
- 保留旧版设置、打开输出、文件导入和通知参数的行为。
- 切换语言时刷新右键菜单；菜单刷新串行处理，避免启动与任务完成刷新互相覆盖。
- 用户隐藏最近输出的选择保存在应用数据目录的 `jump-list-dismissed-outputs.json`。同一路径再次完成转换后可重新出现。新隐藏记录保存失败时保留系统移除标记，等待下次刷新。
- 图标位于 `src/FormatFactoryWinUI/Assets/JumpList-*.png`，可运行 `build/update-jump-list-icons.ps1` 重新生成；构建和发布均会复制这些文件。
