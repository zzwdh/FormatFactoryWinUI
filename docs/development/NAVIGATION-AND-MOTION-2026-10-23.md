# 导航、控件视觉与交互动效

开始日期：2026-10-23，更新日期：2026-10-24。沿用现有中性色、Windows 强调色和 WinUI 原生输入机制。

## 导航与页头

- 常规窄栏宽 80：六个转换分类显示 20 图标和 12 号短标签；完整本地化名称保留在提示及无障碍名称中。
- 展开宽 232：显示图标和完整文字。展开按钮位于顶部独立操作区；窗口宽度缩到 960 以下时收紧导航，为任务内容保留空间。
- 自动化、工具与历史、设置在底部归组；高度低于 640 时，主分类切换为紧凑图标，保留原生导航滚动及完整提示。
- 继续使用 NavigationView / NavigationViewItem 的选中、焦点、键盘与子菜单机制。Content 保留完整字符串，由缓存的原生 DataTemplate 呈现图标与标签，不替换原生输入模板。
- 顶部应用图标、名称与系统标题栏融合；拖拽区与导航按钮分开，保留系统窗口按钮。转换分类页标题对应当前分类。
- 格式、预设、音轨和输出位置选择器采用统一圆角、最小高度及标题层次；菜单统一图标与操作分组；业务弹窗统一标题、间距及选择器样式，默认按钮和危险操作确认仍由原流程决定。

## 动画方案与实现

| 场景 | 方案 | 当前实现 |
| --- | --- | --- |
| 连续拖动窗口、仍处同一布局档 | 布局实时跟随；不追赶鼠标、不延迟控件实际尺寸 | 不新增动画 |
| 宽、中、窄布局跨断点换行 | 新位置立即参与布局，视觉位置用 167ms 缓出衔接 | 读取 ActualOffset 的前后布局坐标，仅对可见 AdaptiveGrid 直接子元素使用 Composition Translation，不动画 Width/Height |
| 连续反复跨断点 | 中断旧过渡，从当前显示位置接续至最新布局 | 同元素重排接续；页面入场/淡出优先，避免争用 |
| 导航展开与收起 | 宽度立即响应，标签用短淡入保持连贯 | 等新标签布局完成后淡入 167ms；快速操作只执行最后一次待入场请求 |
| 同页切换分类 | 当前任务区轻淡出，新任务区轻移并淡入 | 沿用 83ms 淡出、167ms / 6 位移入场 |
| 切换设置、历史、工具等页面 | 用短入场表达层级变化 | 沿用 250ms / 8 位移；快速点击以最后一次请求为准 |
| 按钮悬停、按下、释放与键盘操作 | 反馈作用于当前控件，触发动作立即执行 | 保留 WinUI 原生状态过渡，不叠加整按钮缩放 |
| 下拉菜单与弹窗开合 | 焦点、遮罩和表面开合保持一致 | 使用 WinUI 原生菜单、ContentDialog 动效和系统节奏 |
| 任务新增、删除、状态变化 | 局部反馈，保持原任务与选择状态 | 沿用可见项有限入场、位置变化和状态单次强调 |
| 任务进度 | 始终显示真实进度 | 沿用原生 ProgressBar；不预测或延迟真实值 |

这些数值是本项目采用的节奏，不代表 Microsoft Store 内部参数。

## 边界与验收

- Windows 关闭动画、高对比、窗口失焦、元素卸载或窗口关闭后，自定义重排立即结束并释放捕获。原生控件继续遵循系统偏好。
- 不对整个队列创建动画；保留虚拟化、差量更新及现有进度批处理。
- 缩放时的换行是避免控件挤压和遮挡的自适应行为；动画负责衔接位置，不固定所有控件的坐标。
- 真实 WinUI 检查覆盖所有界面语言的名称与阅读方向、导航按钮实际动作、短窗口入口可达、快速导航终态、跨断点与同档缩放，以及动画关闭和卸载清理。
- 截图用于核对布局与主题，不能单独证明动画流畅度或系统标题栏/Mica 的桌面合成效果。

## 实现依据

### 2026-10-24 窄栏裁切修复

- 用户截图中的“全部任务”标签使用 64 宽模板，但原生 presenter 在 80 宽侧栏中仍保留空图标槽 8 和末端留白 14，剩余内容区不足。现在在 presenter 层回收这两处留白，窄栏内容居中；主分类改用独立图标行和至少 16 高的文字行，展开栏保留图标、文字与箭头的间距。
- 工具子项原先只在父项被调用时展开侧栏，原生箭头展开可绕过该路径。现在监听 `NavigationView.Expanding`，先展开至 232 再显示子项；收窄时同步折叠工具子树，保留已选光盘页面。
- 回归增加真实展开/折叠动作、光盘选择保持，以及中文、阿拉伯语在常规窄栏、短窗口和展开栏下的内部图标/文字边界检查。检查覆盖 presenter 布局槽与祖先裁切区域，避免仅判断外框与窗口相交而漏掉局部裁切。
- 用户原始截图保存在 `work/navigation-ui-fix-20261024/before-all-tasks.png` 和 `before-tools.png`。本轮隔离窗口结果及截图位于 `work/ui-regression/navigation-ui-fix-20261024/`。
- 本轮构建成功；完整真实 WinUI 回归 208 项通过、0 失败，输出 55 张截图。已目视核对常规窄栏、短窗口、工具展开/收起、浅色展开栏及阿拉伯语展开栏。构建仍有现存 `System.Security.Cryptography.Pkcs 8.0.1` 依赖告警。本轮仅修复并验证源代码，未更新当前安装的应用。

布局位置取自 XAML arrange 后的 `UIElement.ActualOffset`，以免底层视觉对象的坐标与实际单元格位置不一致。属性含义参见 [Microsoft 文档](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.uielement.actualoffset?view=windows-app-sdk-2.0)。
