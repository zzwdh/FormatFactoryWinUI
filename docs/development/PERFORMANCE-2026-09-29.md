# 页面拆分性能验收（2026-09-29）

同一台 x64 Windows 11 设备、相同电源和界面环境下，拆页前窗口源码快照与当前页面实现各运行 9 个独立进程。两侧共享当前 Core、Engine、Windows App SDK 2.5.1；大文档使用相同的 2,338,048 字节、2,500 段 DOCX，走内置 DOCX→EPUB 路线并校验输出。指标使用九次样本的 P95，私有内存取该阶段峰值。

| 指标 | 基线 P95 | 当前 P95 | 变化 |
|---|---:|---:|---:|
| 窗口 UI 构造 | 325.59 ms | 306.71 ms | −5.80% |
| 首次设置页初始化 | 36.75 ms | 30.82 ms | −16.13% |
| 2,500 段 DOCX→EPUB | 490.71 ms | 493.77 ms | +0.62% |
| 1,000 项队列筛选往返 | 94.66 ms | 90.06 ms | −4.87% |
| 10,000 项队列筛选往返 | 164.15 ms | 161.23 ms | −1.78% |

大文档峰值私有内存为 183.60→182.88 MB（−0.39%）；五项测量的峰值私有内存均未超过基线。窗口关闭后的句柄差额 P95 为 754→725，但独立进程采样无法证明同一进程内反复创建/关闭窗口没有持续泄漏。完整原始数据见 基线（本地路径 `work/ui-regression/ui-perf-baseline-sep29/performance.json`） 和 当前实现（本地路径 `work/ui-regression/ui-perf-candidate-sep29/performance.json`）；比较器位于 [Compare-Performance.ps1](../../tests/WinUiSmoke/Compare-Performance.ps1)。

按这组可比样本，所有 P95 时延和峰值内存均满足“不比基线退化超过 10%”的本地门槛。该对照只隔离页面和宿主改动，**不等同于上一正式发布包的冷启动**；首次安装、实际用户数据加载、ARM64 真机及长期句柄趋势仍需在发布验收设备上测量。
