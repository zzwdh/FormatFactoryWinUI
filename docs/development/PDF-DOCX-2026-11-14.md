# PDF 转 DOCX

## 使用

导入 PDF，在任务目标格式中选择 **DOCX** 后开始转换。多份 PDF 可通过队列分别转换，也可在自动化规则中选择 DOCX 并将输入扩展名限制为 `.pdf`。密码 PDF 使用任务卡片中的密码输入框；密码继续仅保存在内存中。扫描页使用设置中的 OCR 识别语言及 Windows 已安装的识别能力。

输出采用内置 Open XML 写入器，无需 Word、LibreOffice 或新的第三方依赖。DOCX 包含可编辑文字，保留文字换行、制表符、连续空格、源分页标记，以及文档标题和语言。扫描页自动 OCR；全部页面均未提取或识别到文字时，明确提示失败。

图片、表格结构、字体、栏位及复杂版式不保留。文字会重新排版，Word 中的实际页数可能增加；OCR 的准确度取决于扫描质量和识别语言。任务选择 DOCX 时会显示对应说明。该功能不宣称无损转换。

## 接入

- `formats.json` 将 DOCX 注册为可导出格式；来源明确时仅 PDF 提供该目标，自动化编辑器的通用文档目标列表仍包含 DOCX。
- `DocumentConversionRoutePlanner` 规划 PDF → normalized-document → DOCX；`DocumentConversionService` 复用 `PdfContentExtractor` 的提取、OCR 和密码流程。
- `PdfDocxWriter` 写入真正的 Word 文字段落和分页，清理无效 XML 字符，并校验 DOCX 主正文及 Open XML 结构。未支持的结构块明确拒绝，不静默丢弃。
- 暂存文件校验通过后才提交；取消或失败清理暂存，保留源 PDF。最终提交失败沿用现有的已验证输出恢复流程。
- 队列目标选择、恢复、密码编辑和自动化沿用现有接口。新增提示覆盖现有 44 种语言。
