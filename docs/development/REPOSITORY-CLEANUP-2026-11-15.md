# 生成目录清理与维护（2026-11-15）

源码已按职责分层，本次沿用现有项目、命名空间和资源路径。检查后清理可重建的编译输出、合成测试夹具和打包暂存，保留未提交开发内容。

## 目录用途

| 目录 | 用途与维护方式 |
| --- | --- |
| `src/`、`tests/` | 生产源码、测试、真实测试样例及第三方源码；仅项目直接的 `bin/`、`obj/`、`TestResults/` 可按清单清理 |
| `build/`、`packaging/` | 构建、校验、打包脚本及配置，继续保留 |
| `docs/` | 使用、架构、开发和发布文档，分类沿用现有导航 |
| `outputs/` | 发布成品、品牌、登记资料及历史交付；本次保留所有安装包、校验值及回执 |
| `outputs/copyright/` | 软件登记用源程序 PDF、设计说明书 DOCX/PDF |
| `work/` | 引擎缓存、源码快照、验证记录及生成目录，不可整体删除 |
| `tmp/` | 临时文件位置，已加入忽略规则；当前空目录已移除 |

登记源程序 PDF 从 `output/pdf/` 移至 `outputs/copyright/`，移动前后 SHA256 相同。原来的 `output/pdf/`、`output/` 及 `tmp/pdfs/`、`tmp/` 均为空后移除。`.gitignore` 合并了重复的输出规则，并补充根目录 `tmp/`。

## 清理边界

- 清理 `src/`、`tests/` 中项目直接的编译及测试结果目录。
- 清理历史 UI 回归运行的 `artifacts/bin/` 和 `artifacts/obj/`；保留运行根目录中的结果、性能与启动报告、截图、测试输入、状态数据和生成项目。
- 清理 `engine-packaging-tests-<GUID>`、`release-gate-tests-<GUID>` 合成夹具；它们由测试脚本重新创建，不是真实设备验收证据。
- 清理 `msix-staging-x64/arm64`、`publish-msix-x64/arm64` 和 `msix-bundle` 暂存目录；保留 `outputs/msix/` 成品及 `work/prepared-engines/`。
- 保留引擎下载、已准备引擎、第三方许可证、历史源码快照、Sentry 证据和其他未确认用途的工作目录。含目录链接的引擎裁剪测试夹具不在自动清理范围内。

五次启动测量的旧编译目录含指向 `work/prepared-engines/x64/Engines` 的 Junction。本次逐项核实目标后只解除链接，再清理编译目录，没有递归删除引擎目标。自动清理脚本遇到任何目录链接均跳过该目标。

## 日常使用

使用 PowerShell 7，从仓库根目录运行。默认只列出清单：

```powershell
./build/clean-generated.ps1
```

关闭应用、构建和测试进程后执行清理，并保留报告：

```powershell
./build/clean-generated.ps1 -Apply -ReportPath work/cleanup-report-20261115.json
```

报告使用新的仓库内 `.json` 路径，不覆盖已有文件。脚本只接受固定生成目录白名单，删除前复核仓库边界、Git 跟踪文件和目录链接；应用、构建或测试仍在运行时拒绝执行。

清理后首次运行必须重新构建，不能直接使用原先依赖这些目录的 `--no-build`、`--no-restore` 或 UI `-SkipBuild`。本次维护不代表新的功能回归、安装验证或发布验收。
