# 性能专项实施记录（2026-09-12 至 2026-09-13）

按本次确认的方向，重点处理启动、批量导入、队列刷新和大文档转换中的额外工作。沿用原有转换质量、编码预设、取消与恢复行为；不开展细致性能基线、耗时排名或长期采样，因此本记录不宣称未经测量的加速比例。

## 已实施

| 范围 | 改动与作用 |
|---|---|
| 启动与设置 | 工具发现与硬件读取并行推进，跳转列表延后；设置页首次进入才创建并读取原生能力目录。自动检测结果回填到模型，保留设置草稿、语言和主题行为；打开设置不会重置当前省电策略。 |
| 批量导入 | 普通文件最多同时探测 2 个，并按原始顺序交付；组合输入和实体光盘保留顺序屏障；文件夹复用已枚举结果，恢复队列也走受限并发。 |
| 任务进度与列表 | 进度按任务保留最新值，每 200 毫秒合并更新界面、通知与任务栏；完成状态即时更新，重启任务隔离旧进度。批量增删只安排一次刷新，过滤使用增量更新，减少整表重建。 |
| 队列保存 | 在调用处捕获独立快照，后台串行写入并合并尚未开始的保存请求；保留跨进程协调、检查点、原子替换和落盘等待。 |
| 日志 | 使用有容量上限的后台写入队列，按文件合并内容；任务结束、退出和错误日志仍有显式刷新与失败反馈。 |
| 历史记录 | 缓存未变化文件的解析结果，保留最多 1000 条；搜索延迟 250 毫秒并取消过期查询。完成任务先释放转换槽，再写历史和搜索索引，退出仍等待收尾。 |
| 后台执行 | 文档与光盘转换入口放到后台，完成后的历史记录及系统索引也在后台执行；启动失败仍可保存并退出，窗口关闭后跳过后台界面回调。 |
| 图片和文档 | 解码/OCR 按页推进，图片资源使用工作目录中的文件并由写出阶段流式读取；TXT 路线省去 PNG 编码，减少整本文档的图片字节副本。 |
| ISO/CSO | 转换过程复用压缩缓冲区，减少每个块的额外分配，并限制过程通知频率；压缩级别、块尺寸和数据校验保持原有行为。 |
| CPU 自动分配 | 低核心数设备允许每个转换分配 1 个线程，按可用核心数和并发任务数计算，减少过量争抢；用户明确指定的线程数行为保持兼容。 |
