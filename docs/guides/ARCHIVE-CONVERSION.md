# 压缩包格式互转

## 本次确定的范围

本工具只做压缩包格式互转，不提供压缩包内容管理或普通文件新建压缩包。本次不调整使用数据遥测、自动错误报告及其默认设置。

入口位于主导航“压缩包互转”，与视频、音频、图片、文档、电子书及光盘并列。工具使用独立的压缩包批量任务列表，每个原包生成一个目标包。

| 输入 | 输出 |
| --- | --- |
| ZIP、7Z、TAR、TAR.GZ、TAR.XZ、RAR | ZIP、7Z、TAR、TAR.GZ、TAR.XZ |

RAR 只作输入，不生成 RAR。分卷输入合并为一个完整目标包，不生成分卷输出。同一压缩包的完整分卷应放在同一文件夹；加入多卷时归并为一个任务。

分卷输入包括 RAR 的 `.part01.rar`／`.r00`、7Z／ZIP 的 `.001` 数字分卷，以及 ZIP 的 `.z01`／`.z02`／`.zip` 分卷。可选择同组任一卷，工具会定位读取入口；多选同组卷时只建立一个任务。缺少分卷时显示失败并保留原包。

## 使用流程

1. 添加需要互转的压缩包，选择输出文件夹。
2. 在“整批输出设置”中选择目标格式、是否加密及是否进行严格校验。整批只设置一次，等待中的单个任务仍可修改自己的输出设置。
3. 点击“开始转换”。需要源包密码时才弹窗输入；密码错误时可以重新输入，也可以跳过该包。
4. 某个包损坏、缺少分卷或转换失败时，该任务显示失败原因，其他任务继续执行。

原包始终保留。目标位置出现同名文件时自动编号，不覆盖已有文件。工具不保存源包或输出密码；关闭工具或取消操作后，不提供密码恢复。

## 输出加密

输出是否加密、使用什么密码由用户选择，与源包密码独立。ZIP 和 7Z 输出支持加密；TAR、TAR.GZ、TAR.XZ 不支持输出加密，设置中应明确提示并要求改用支持加密的格式或关闭输出加密。

启用输出加密时需要输入并确认密码。源包即使已加密，也不会自动决定新包的加密状态。

ZIP 使用 AES-256，输出密码限 1–99 个可见 ASCII 字符；需要中文密码时请选择 7Z。7Z 支持 Unicode 密码（最长 1,024 个字符）并加密文件名，两种格式都不接受控制字符。界面会先校验密码。密码通过进程标准输入传递，不进入命令行参数或临时文件。

## 校验与异常处理

默认进行标准校验，确认目标压缩包完整可读。可勾选“严格内容校验”，额外逐个比对包内文件内容；严格校验需要更多时间和临时空间。

校验失败不作为成功结果交付。取消会停止当前处理并清理临时文件及未完成输出，已经完成的输出和原包保留。切换页面不会停止转换；退出应用会取消正在处理的压缩包任务并等待清理。应用启用托盘且仍有转换时，窗口关闭沿用现有的最小化到托盘行为。

包内不安全路径或链接不直接解包到用户文件夹；无法安全处理的包显示失败。普通文件内容和目录结构属于转换与校验范围；压缩包注释、平台特有权限及链接等高级元数据不保证跨格式保留。

临时解包、输出暂存和严格校验副本均放在输出文件夹所在磁盘，开始时根据包内声明大小检查可用空间；成功、失败或取消后清理本次临时目录。压缩包任务单独保存，重新打开应用后恢复来源、输出格式、校验方式和加密开关，由用户手动开始。中断任务从头重新转换；完成结果保留，并进入统一转换历史。源包及输出密码只在当前会话中保留，加密输出恢复后需要重新输入密码。

任务行显示已完成结果的体积变化与耗时，页面显示最近批次的成功、失败和取消汇总。历史记录可再次加入压缩包列表，沿用安全保存的参数。任务恢复文件损坏或无法读取时保留原文件并显示提示；保存失败时也会明确提示。具体行为见[任务体验说明](TASK-EXPERIENCE.md)。

本功能提供英语、简体中文和繁体中文界面，其他界面语言暂时显示英语；既有功能的译文不变。

## 引擎与发布状态

运行时使用随应用分发的官方 7-Zip 命令行引擎。下载来源、版本、文件摘要和许可证随打包配置记录。

开发环境可单独准备原生引擎，无需重新准备其他转换工具：

```powershell
pwsh -NoProfile -File packaging/archive/Prepare-ArchiveEngine.ps1 -Architecture all
```

准备结果位于 `work/prepared-archive/{x64,arm64}/Engines/7zip`。发布主流程会通过锁定来源和文件回执将其纳入正式引擎目录；本地直接运行应用时，需将对应架构的 `Engines/7zip` 放在应用目录。准备和测试不安装系统 7-Zip，也不修改文件关联。
