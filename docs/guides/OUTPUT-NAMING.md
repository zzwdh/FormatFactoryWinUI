# 输出命名和路径预览

在转换队列的“输出设置”中选择常用模板，或编辑模板并用按钮在光标处插入占位符。

| 占位符 | 内容 |
| --- | --- |
| `{name}` | 原文件名，不含扩展名；实体光盘使用卷标或驱动器标识 |
| `{format}` | 目标格式 |
| `{date}` | 转换开始时的本地日期，格式为 `yyyyMMdd` |
| `{preset}` | 当前输出标签；未设置标签时使用转换模式标识，例如 `balanced`、`quality` |
| `{width}`、`{height}` | 已探测到的**源文件**像素尺寸；没有该信息时为 `unknown`，不表示转换后的尺寸 |

例如，源文件 `holiday.mov` 的输出标签为 `Mobile`，目标格式为 MP4，模板 `{name}_{preset}_{format}` 会生成 `holiday_Mobile_MP4.mp4`。扩展名自动添加，不应在模板内重复输入。未使用 `{preset}` 时，输出标签仍会自动附加，方便区分同一来源的多个输出。

预览优先使用当前选中的任务，否则使用队列第一项；空队列显示明确标注的示例。同组多个输出最多展示前三项。编辑模板、选择常用模板或切换保留目录结构时，完整路径会自动更新。

预览会考虑目标文件夹、源目录模式、保留目录结构、已有文件、正在转换的预留路径以及同一组预览内部的重名。例如 `holiday.mp4` 已存在时显示 `holiday (1).mp4`。帧序列、蓝光 MKV 和音乐 CD 等目录输出使用其实际目录名称。

预览不会创建文件或目录、申请磁盘预算或占用文件名。后台检查路径时可取消，不会持有真实输出的预留锁。同名冲突可能在预览后发生变化，最终名称由转换开始时的预留操作确定；已有文件保持不变。

模板最多 160 字符，禁止路径分隔符、未知占位符和保留设备名。只有保存后才更新设置；取消或仅编辑预览不会修改当前设置。
