# 用户自定义自动化

在侧边栏打开“自动化”，创建规则并保存。每条规则包含输入文件夹、触发方式、文件筛选、一份或多份输出配置、输出文件夹和原文件处理方式。

## 创建规则

1. 为规则命名并选择输入文件夹，可选择包含子文件夹。
2. 按需要启用文件夹监视、每日定时执行；所有已启用的规则都可以手动运行。
3. 按文件类型、扩展名或文件名筛选。扩展名用逗号分隔，文件名支持 `*` 和 `?`。
4. 选择目标格式、质量模式和输出文件夹；点击“多种输出”可添加各自具有独立格式、质量、尺寸或体积上限的输出。可使用输入文件夹下的 `Converted` 子文件夹，输出目录会被排除在自动化输入之外。
5. 默认保留原文件。可选择成功后将原文件移到归档文件夹；不提供自动删除原文件。
6. 保存后生效。使用上下箭头调整优先级；同一文件只执行第一条匹配的已启用规则。

## 预览与转换预设

点击“预览规则”可检查尚未保存的配置。预览列出输入、预计输出和处理原因，包括筛选不匹配、被前面的规则接管、已经处理、之前取消或失败、文件正在写入及输出／归档排除。预览最多显示 500 个文件，不保存规则、不加入队列、不创建输出目录，也不移动原文件。实际转换仍会检查文件内容与引擎可用性；其他任务创建文件或源文件发生变化时，预计输出名称可能改变。

在转换区域可选择保存的转换预设，也可展开保存区，为当前转换参数命名并保存。任务队列的任务菜单提供“将任务保存为转换预设”。预设保存目标格式、质量模式和适用的转换参数，不包含输入目录、输出目录、访问令牌、归档位置或密码。

预设也可保存完整输出组合。多输出按来源在队列分组，每份结果可独立操作；部分失败保留已成功结果，重试不重复转换成功成员。只有全部输出及历史记录可靠保存后才记录整组成功和归档源文件，取消或删除任一自动化成员不会使剩余成员提前满足归档条件。参数范围与大小限制见 [自定义转换参数与多种输出](CONVERSION-OUTPUT-OPTIONS.md)。

高级转换选项提供 OCR 语言、电子书版式、DOCX 修复、图片色彩策略、兼容音轨、输出命名模板和保留目录结构。只显示适用的选项；空白字段和未确定的复选框沿用软件设置。应用预设会将参数复制到当前规则草稿，保存规则后才生效；更改或删除预设不会改变已保存规则和已入队任务。

## 启动补处理与自动重试

每条规则可以开启“启动时处理遗漏文件”。启动后扫描未成功处理的文件版本，包括软件关闭期间到达的文件；沿用文件写入稳定检查、规则优先级及输出／归档排除。只有补处理开关启用的规则才改变启动行为，原有规则默认关闭。已经进入队列且参数快照一致的等待或失败任务会复用原任务，不创建重复行；有人工暂停、阻塞或参数不同的待处理任务时先等待用户处理。

自动重试次数可设置为 0–5 次，间隔为 1–3600 秒。默认 0 次，保留原有行为。只有明确识别为暂时性的文件共享冲突、设备忙或网络断开等错误才自动重试；格式不支持、文件损坏、缺少密码、权限不足和空间不足等错误保留供用户处理。已经验证且暂存的输出继续通过“保存结果”恢复，不自动重新转换。

重试沿用原任务和规则参数快照；等待期间修改、停用规则或取消任务会停止后续自动尝试。用户修改失败任务的参数后也会停止自动重试，保留修改供队列手动重试。删除任务时会在退出前保存取消记录。失败次数及下次尝试时间保存在本地，重启或暂缓不会重置次数限制。达到上限或发生永久性失败后，相同文件版本不再自动触发，可手动运行规则或在队列中重试。取消的文件版本保持取消；需要再次处理时在任务队列中主动重试。源文件版本发生变化后可以重新处理。

第一条匹配规则即使只有手动触发，也会阻止后续规则自动处理相同文件。需要让监视或定时规则接管时，请调整顺序或停用前面的规则。

## 触发与去重

- **文件夹监视**：启用、重新配置或启动软件时先建立基线，已有文件不会立即开始转换。随后发现新增或发生变化的文件，等待文件写入稳定后再处理。
- **手动运行**：扫描当前文件夹内符合规则的文件；失败或未处理的文件可以再次尝试。
- **每日定时**：使用电脑的本地时间，每天到达选定时间后扫描一次。当天软件较晚启动时会补做当天的扫描。文件夹不可访问时稍后再尝试。
- 成功处理的文件版本会记录在本地。相同路径、大小、修改时间及创建时间的版本会跳过；文件变化后可重新处理。
- 输出和归档目录会从所有规则的输入中排除，避免结果再次进入转换流程。规则不支持将另一条规则的结果作为后续步骤。

转换任务进入现有队列，保留进度、暂停、取消和历史记录。失败任务可以在队列中重试，重试继续使用任务保存的格式、质量模式、输出及归档设置。输出重名时自动增加编号，不覆盖已有文件。

停用或修改规则影响后续触发，已经进入队列的任务继续使用原来的规则快照。需要停止正在执行的任务时，在任务队列中取消。

## 原文件归档

只有转换成功且输出存在时才尝试归档。归档前再次检查源文件版本；文件发生变化或正在写入时保留原文件，并报告原因。归档重名同样自动增加编号。转换成功但归档失败时保留转换结果和原文件，界面显示原因。

## 软件运行期间

自动化随应用进程运行。有监视、定时或启动补处理规则启用时，关闭主窗口会保留托盘运行；在托盘选择退出后暂停自动化。可在设置中启用开机启动。

未开启启动补处理时，软件关闭期间到达的文件不会在下次启动时作为“新增文件”自动转换；可通过手动运行或定时扫描处理。开启补处理的规则可复用参数快照一致的等待或失败任务，其余恢复的队列仍需用户主动继续或重试。

规则、成功记录、取消／失败版本、重试进度和每日扫描记录保存在应用数据目录的 `automation.json`。转换预设独立保存在 `automation-presets.json`。任务队列另外保存规则快照，以便恢复后重试。密码不写入规则或预设；遇到需要密码的文件时，在任务界面处理。

配置损坏时暂停自动化并显示错误，保留原文件。不会将损坏的配置默认为空配置后覆盖。
