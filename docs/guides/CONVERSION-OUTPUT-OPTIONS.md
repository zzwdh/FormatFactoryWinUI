# 自定义转换参数与多种输出

在任务队列的“更多”菜单选择“自定义转换设置”，或选中多项任务后从页面“更多”菜单进入。设置保存在任务中，也会随预设、转换历史和队列恢复保留；空白参数沿用已有质量预设。

## 指定大小与参数

- **最大体积**表示每份输出文件的大小上限，而不是整个输出组合的总大小。界面使用 MB，1 MB = 1,048,576 字节。
- 视频支持最大宽度、高度、帧率、视频码率和音频参数。宽高作为上限，保持比例且不放大；音频支持码率、采样率以及单声道或立体声。
- 静态图片支持宽高上限；JPG、WebP、AVIF 还支持质量（1–100）和最大体积。指定体积时自动寻找合适的编码质量，保留像素尺寸；只有用户填写较小的宽高时才缩小。
- 严格体积上限支持 MP4、MKV、MOV、WebM、H264、HEVC、VP9、AV1，以及 MP3、M4A、AAC、Opus、Vorbis、OGG、AC3、EAC3、WMA。有损视频和音频最多编码三次；图片质量搜索最多九次。
- 体积上限与固定视频码率、音频输出的固定码率、固定图片质量互斥；视频的音频码率可以另行指定，并计入总预算。
- 无损转换、动画、多页图片、帧序列、ICO 和不支持限额的目标格式保留原有转换方式。它们不会为达标被自动改成有损、丢帧、丢页或截短。
- 最终文件只有在实际大小符合上限、时长或图片尺寸验证通过后才提交。无法满足时保留源文件并提示提高上限、调整尺寸或更换格式，不交付超标或截短结果。

## 一次生成多种输出

在任务“更多”中选择“多种输出”，添加各输出的格式、预设、自定义参数和名称。也可批量选择来源后配置相同的输出组合。名称用作文件名后缀，例如 `课程_高清.mp4`、`课程_分享.mp4`、`课程_音频.mp3`；同一格式可以使用不同参数多次输出，现有重名保护继续生效。

配置后队列按来源分组，展开可查看每份结果的进度，并分别暂停、取消、重试、预览、复制或打开。各输出遵守现有并行数量设置，某项失败不会撤回已成功的结果。组内已经产生成功输出后，整体组合不再重配，以免重复转换；未完成输出仍可单独调整参数。

“保存输出组合”将全部配置存为可复用预设。编辑器可载入保存的组合；应用时复制参数，更改预设不会修改已入队的任务。

## 自动化与恢复

自动化规则中的“多种输出”使用同一个编辑器。规则预览列出每份预计输出；所有结果成功且可靠保存后才记录整组完成并归档原文件。部分失败或取消时保留源文件，成功结果继续可用。自动重试只处理临时失败，手动“立即运行”还可重新尝试此前无法转换的输出。

归档失败时保留已完成结果和待归档的组合，重启恢复后可继续归档，无须重新转换。若原文件在转换过程中发生变化，则保留新版本并提示，避免移动与当前结果不对应的文件。

尚未结束的组合会持久保存成功成员及其输出位置。重启时验证已有结果，不要求重新读取已成功成员的输入；未完成成员沿用原有恢复、手动继续及自动化补处理策略。规则或组合预设旧版配置自动迁移为单输出，损坏或未来版本配置不会被覆盖。密码仍仅保存在当前进程内存中。

多输出支持视频、音频、图片、文档和电子书的既有转换路线，例如视频生成分享版和 MP3、扫描图片生成 PDF 和 Markdown；光盘与镜像工具保持原有任务方式。
